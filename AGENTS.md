# Development instructions

Read docs/scope.md and docs/progress.md before making changes.
Work only on the current requested task; do not skip milestones.
Explain unfamiliar concepts and reviewable changes in simple English.
Use PowerShell for host commands; label Linux-container commands clearly.
Keep business rules deterministic and monetary calculations decimal-based.
Keep company data isolated. Never commit secrets or real financial documents.
Add meaningful tests for business rules, permissions, and failure recovery.
Run relevant checks and state accurately what passed or failed.
Record important decisions and update progress after completed work.
